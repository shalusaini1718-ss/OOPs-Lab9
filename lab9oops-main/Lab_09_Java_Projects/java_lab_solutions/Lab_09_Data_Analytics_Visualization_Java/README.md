# Lab Sheet-09 — Java Data Analytics and Visualization
Projects from the supplied lab sheet:
1. COVID-19 Data Analysis Dashboard
2. Sales Data Analysis Dashboard

## Requirements
- JDK 17 or newer
- No external libraries required.
- CSV files are included as small sample datasets. Replace them with a trusted, current dataset for real analysis.

## Run
```bash
javac CovidDashboard.java
java CovidDashboard covid_data.csv
```
```bash
javac SalesDashboard.java
java SalesDashboard sales_data.csv
```
Both programs perform basic missing/invalid-row handling and print chart-ready summaries with ASCII bar charts. They are console dashboards, so screenshots of the terminal output can be included in the submission.
